\begin{abstract}
This report documents PoolForge, a debiasing method that uses no bias labels during training, together with the code
needed to reproduce every number in it. PoolForge extends Learning from Failure (LfF)~\cite{nam2020lff} with a memory
pool that collects the training images a biased model keeps failing on, and with three sources of extra training images
built from that pool: same-class mixup, a learned edit generator judged by the biased model, and a PGD perturbation.
All models are trained from scratch on Colored MNIST, Corrupted CIFAR-10 and BFFHQ with the same code, backbone and
selection rule. Over three seeds PoolForge reaches \PFavg\ average bias-conflicting test accuracy against \LFFavg\ for LfF.
We report the setup, baselines, results at four bias ratios, ablations of every part, and a case study of the images
each part produces and of the test groups on which PoolForge does best and worst.
\end{abstract}

\section{Problem setting}
\label{sec:setting}
Each training image has a label $y$ and a bias attribute $b$ (digit color, corruption type, or gender). For every class
$y$ the training set has one bias value $a(y)$ that occurs with almost all images of that class. An image is
\emph{bias-aligned} if $b=a(y)$ and \emph{bias-conflicting} otherwise. The share of conflicting images in the training
set is the \emph{bias ratio} (0.5\%--5\% here). The bias attribute is never given to any method during training; it is
used only to compute the metrics below and the diagnostics in Section~\ref{sec:case}.

\textbf{Metrics.} We report test accuracy averaged over (class, bias) groups:
\emph{bias-conflicting} accuracy (mean over groups with $b\neq a(y)$; the main metric),
\emph{unbiased} accuracy (mean over all groups) and \emph{worst-group} accuracy (minimum over groups).
$a(y)$ is the most frequent bias of class $y$ in the training set.

\section{Method}
\label{sec:method}
Figure~\ref{fig:flow} shows one training step. PoolForge trains two networks of the same architecture: a biased model
$f_b$ and a debiased model $f_d$. Only $f_d$ is used at test time. Parts \pC, \pD\ and \pE\ start at step 2000; the
pool \pB\ is refreshed every 1000 steps from then on.

\subsection{\pA\ LfF reweighting}
$f_b$ is trained with generalized cross-entropy (GCE~\cite{zhang2018gce}, $q=0.7$). For every training image we keep
exponential moving averages ($\alpha=0.7$) of the cross-entropy of $f_b$ and $f_d$, $\ell_b$ and $\ell_d$, normalized
by the class maximum. $f_d$ is trained with cross-entropy weighted by $w=\ell_b/(\ell_b+\ell_d)$. This part is LfF
unchanged~\cite{nam2020lff}.

\subsection{\pB\ Memory pool}
At each refresh, the images of each class are ranked by $\ell_b$. The top $k_c$ share of class $c$ receive $+1$ in a
per-image count, after all counts are multiplied by $0.8$. The pool of class $c$ is the $k_c$ share of its images with
the highest count (ties broken by the current rank). $k_c=1\%$ until 25\% of training; after that
$k_c$ is the share of class-$c$ images with $\ell_b>\ln 2$, clamped to $[1\%, 20\%]$. The pool uses only $f_b$'s
losses, not bias labels.

\subsection{\pC\ Pool mixup}
At every step we draw 32 pairs $(x_a,x_b)$ of the same class $y$ from the pool and add
$\mathrm{CE}(f_d(\lambda x_a+(1-\lambda)x_b), y)$ with $\lambda\sim U(0,1)$ to the loss.

\subsection{\pD\ Pool generator}
At every step we draw 64 pool images $(x,y)$ and a random target class $k\neq y$ for each. The generator $G(x,k)$
is a two-layer convolutional encoder conditioned on $k$ that outputs: a $3\times3$ color matrix $I+0.5\tanh(\cdot)$ and
a color shift, a low-resolution residual ($8\times8$, amplitude $0.5$), a weighted sum of four learned $5\times5$
filters applied to $x$, and per-channel Gaussian noise with a learned scale. $G$ minimizes
$\mathrm{CE}(f_b(G(x,k)),k)+\|G(x,k)-x\|_2^2$ with Adam; $f_d$ receives $\mathrm{CE}(f_d(G(x,k)),y)$. $f_b$ is in
evaluation mode and receives no gradient from this term. All resizing inside $G$ is done by fixed matrix
multiplication so that training is deterministic (Section~\ref{sec:setup}).

\subsection{\pE\ Pool PGD}
At every step we draw 64 pool images and run 5 steps of PGD~\cite{madry2018pgd} with step size $\epsilon/4$,
$\|\delta\|_\infty\le\epsilon=8/255$ (pixel scale), maximizing
$\mathrm{CE}(f_b(x+\delta),y)-\mathrm{CE}(f_d(x+\delta),y)$. $f_d$ receives $\mathrm{CE}(f_d(x+\delta),y)$. Both
networks are in evaluation mode during the attack.

\subsection{Total loss and origin of each part}
The loss on $f_d$ is the sum of the weighted CE of \pA\ and the terms of \pC, \pD\ and \pE, each with weight 1.0;
$f_b$ is trained by GCE only. Table~\ref{tab:origin} lists where each part comes from.

\section{Datasets}
\label{sec:data}
We use the releases of DisEnt~\cite{lee2021ldd} (Table~\ref{tab:data}). \textbf{Colored MNIST} (CMNIST): digit
classification, bias = digit color, $28\times28$. \textbf{Corrupted CIFAR-10} (C-CIFAR10)~\cite{hendrycks2019corruptions}:
object classification, bias = one of 10 corruption types, $32\times32$. \textbf{BFFHQ}~\cite{karras2019ffhq,lee2021ldd}:
age (young/old), bias = gender, $128\times128$ resized to $224\times224$. Each split is a fixed list of files, read in
sorted order and cached once. The bias-ratio variants change only the training and validation sets.

\section{Baselines}
\label{sec:baselines}
All baselines are reimplemented in the same code base (\texttt{poolforge/methods/}) and use the same data loading,
backbone, optimizer and selection rule as PoolForge; none uses bias labels or pretrained weights.
\begin{itemize}\setlength\itemsep{0pt}
\item \textbf{Vanilla:} cross-entropy.
\item \textbf{LfF}~\cite{nam2020lff}: part \pA\ alone.
\item \textbf{JTT}~\cite{liu2021jtt}: a first model is trained for $T$ epochs; its misclassified training images are upsampled by $u$ when a new model is trained. $(T,u)=(5,100)$ on CMNIST, $(5,50)$ on C-CIFAR10, $(1,50)$ on BFFHQ.
\item \textbf{LC}~\cite{liu2023lc}: logit correction with the class--bias prior estimated from $f_b$'s predictions (EMA 0.5, $\eta=1$) plus group mixup between minority and majority images of the same class.
\item \textbf{LDD / DisEnt}~\cite{lee2021ldd}: separate intrinsic and bias encoders, relative-difficulty weights, and bias-feature swapping after 10{,}000 steps; its own 50{,}000-step schedule with learning-rate decay.
\end{itemize}

training logs. \textbf{Hardware:} one NVIDIA GPU per run, PyTorch 2.5.1.

\section{Reproduction}
\label{sec:repro}
\begin{enumerate}\setlength\itemsep{0pt}
\item \texttt{pip install -r requirements.txt} (Python 3.10+, CUDA GPU).
\item \texttt{python prepare\_data.py} downloads the DisEnt release into \texttt{data/} and builds the caches.
\item \texttt{python run.py --group all --gpus 0,1} trains every run of this report into \texttt{runs/}; finished runs are skipped. \texttt{--group baselines|ours|ablations|case\_study} or \texttt{--exp NAME} select a subset; \texttt{--list} shows what is done.
\item \texttt{python results.py} evaluates the saved checkpoints and writes all tables to \texttt{results/}.
\item \texttt{python case\_study.py} writes the case-study figures and statistics.
\item \texttt{bash report/build.sh} rebuilds this PDF from those files.
\end{enumerate}
Each run writes \texttt{history.csv} (all metrics at every evaluation), \texttt{result.json} and the selected
checkpoint \texttt{best.pt}. \input{runtime_text.tex}
